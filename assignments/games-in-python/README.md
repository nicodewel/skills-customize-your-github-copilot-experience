# 📘 Assignment: Hangman Game Challenge

## 🎯 Objective

Create a playable Hangman game in Python that uses string handling, loops, and user input to guess a hidden word before running out of attempts.

## 📝 Tasks

### 🛠️ Build the Hangman game

#### Description
Build a Python program that randomly selects a word and lets the player guess letters one at a time. The game should track which letters have been guessed, reveal correct matches, and end when the word is solved or the player runs out of chances.

#### Requirements
Completed program should:

- Choose a word at random from a predefined list
- Show the current word state using underscores for unrevealed letters
- Accept single-letter guesses from the player
- Reveal correct letters in the correct positions
- Track remaining attempts and previously guessed letters
- End with a clear win or lose message
- Prevent invalid input such as empty entries or multiple letters
